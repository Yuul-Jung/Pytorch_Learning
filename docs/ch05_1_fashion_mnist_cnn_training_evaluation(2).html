06CNN 모델 구성 — 이미지 Shape가 어떻게 변하는가

이 실습의 핵심입니다. 28×28 흑백 이미지가 두 번의 합성곱과 풀링을 거쳐 16개의 7×7 특징맵으로 변하고, 마지막에 784개 숫자로 펼쳐져 10개 클래스 점수로 바뀝니다.

CNN 생성 Cell 19
CODE원본 코드
def make_cnn():
    return nn.Sequential(
        nn.Conv2d(
            1,
            8,
            kernel_size=3,
            padding=1
        ),
        nn.ReLU(),
        nn.MaxPool2d(
            kernel_size=2,
            stride=2
        ),

        nn.Conv2d(
            8,
            16,
            kernel_size=3,
            padding=1
        ),
        nn.ReLU(),
        nn.MaxPool2d(
            kernel_size=2,
            stride=2
        ),

        nn.Flatten(start_dim=1),
        nn.Linear(
            16 * 7 * 7,
            10
        )
    )

torch.manual_seed(RANDOM_SEED)

model = make_cnn().to(device)

print(model)

  (2): MaxPool2d(kernel_size=2, stride=2, padding=0, dilation=1, ceil_mode=False)

코드 풀이 — 이 코드가 무엇을 하는가

`nn.Sequential` 안에 Conv2d → ReLU → MaxPool2d를 두 번 배치하고 마지막에 Flatten → Linear를 연결합니다.

nn.Conv2d(1, 8, kernel_size=3, padding=1)
입력 채널 1개에서 3×3 Filter(필터) 8개를 사용해 특징맵 8개를 만듭니다. padding=1 덕분에 공간 크기 28×28은 유지됩니다.
nn.ReLU()
음수 값을 0으로 만들며 비선형성을 추가합니다. Shape는 바뀌지 않습니다.
nn.MaxPool2d(kernel_size=2, stride=2)
2×2 영역마다 가장 큰 값 하나를 남겨 28×28 → 14×14로 줄입니다.
nn.Conv2d(8, 16, kernel_size=3, padding=1)

def train_one_epoch(
    model,
    data_loader
):
    model.train()

    loss_sum = 0.0
    correct = 0
    total = 0

    for images, labels in data_loader:
        images = images.to(device)
        labels = labels.to(device)

        optimizer.zero_grad()

        logits = model(images)

        loss = loss_function(
            logits,
            labels
        )

        loss.backward()
        optimizer.step()

        predictions = logits.argmax(
            dim=1
        )

        loss_sum += (
            loss.item()
            * images.size(0)
        )

        correct += (
            predictions == labels
        ).sum().item()

        total += labels.size(0)

    return (
        loss_sum / total,
        correct / total
    )

model(images.to(device)).cpu()

대각선

대각선 밖

def shift_right(
    images,
    pixels=2
):
    shifted = torch.zeros_like(
        images
    )

    shifted[
        :,
        :,
        :,
        pixels:
    ] = images[
        :,
        :,
        :,
        :-pixels
    ]

    return shifted
