## 01 | 개요·진행 일정

### 과제

기준 모델과 실제 학습된 LoRA 어댑터를 동일 조건에서 추론하여 결과를 기록하고, 성능 향상 주장의 근거를 판단한다.

### 60분 운영

0~10분: 비교 설계 / 10~20분: 데이터·환경 준비 / 20~40분: 코드 실행 / 40~50분: 결과 분석 / 50~60분: 평가·정리.

### 학습 성과

① 공정 비교 조건을 설명한다. ② 기준선 추론 결과를 저장한다. ③ 학습 어댑터가 있으면 동일 평가로 비교한다. ④ 실제 측정과 예시를 구분한다.

### 중요

이번 차시는 1일차 마지막 차시이다. 04차시는 LoRA 구조를 확인했을 뿐 학습 완료를 보장하지 않는다. 학습된 어댑터가 없다면 학습 전후 성능 비교는 성립하지 않는다.

---

## 02 | 배경·선수지식

### 기준 모델

사전학습 또는 지시문 튜닝된 원본 모델. 이번 예제에서는 Qwen/Qwen2.5-0.5B-Instruct를 선택한다. 과정안내서 지정 모델이 아닌 제작 선택이다.

### 학습 어댑터

학습을 통해 변경된 LoRA 행렬을 저장한 디렉터리. adapter_config.json과 어댑터 가중치 파일 등이 있어야 한다. 단순 get_peft_model() 호출은 학습이 아니다.

### 비교의 최소 요건

같은 질문·채팅 템플릿·토크나이저·생성 옵션·하드웨어를 유지한다. 검증 데이터는 학습 데이터와 분리한다.

### 주의

정답률이 상승해도 다른 질문에서 악화될 수 있다. 응답 시간은 초기 모델 적재·GPU 워밍업·메모리 상태에 민감하다.

---

## 03 | 핵심 원리와 평가 척도

### 평가 구조

평가 입력 X → 기준 모델 f_base(X) / 학습 모델 f_adapter(X) → 출력 비교. 같은 입력에 대한 출력 차이가 곧 품질 향상을 뜻하지 않는다.

### 정확성

정답이 명확한 문항은 사전에 정의한 채점 기준으로 점수를 계산한다. 자유서술형은 근거성·정확성·누락·환각 여부를 별도 판정한다.

### 속도

각 문항 생성 소요 시간(초)을 기록한다. 모델 최초 실행의 워밍업 비용과 실험 반복 편차를 따로 기록한다.

### 재현성

모델 식별자·어댑터 경로·라이브러리 버전·GPU 이름·평가 질문·출력 JSON을 함께 보존한다.

## 04 | 모델 비교 구조도

### 처리 흐름

평가 CSV → 동일 질문/템플릿 → [기준 모델] → base 응답 → 결과 JSON
                         ↘ [기준 모델 + 학습된 LoRA] → adapter 응답 ↗

### 판정 흐름

결과 JSON → 문항별 답변 검토 → 정확성·근거성 채점 → 차이 분석 → 개선 여부 판정.

### 데이터 분리

학습 데이터와 평가 데이터는 분리해야 한다. 질문을 외워 답하는 현상을 성능 향상으로 오인하지 않도록 중복·유사 중복을 점검한다.

### 통제 항목

프롬프트, max_new_tokens, do_sample=False, 실행 환경, 입력 순서. 어댑터를 바꾸는 것 외의 조건을 가능한 한 고정한다.

## 전체 Python 실습 코드

```python
"""06차시: 기준 모델과 학습 완료된 LoRA 어댑터의 공정한 추론 비교."""
import argparse
import csv
import json
import time
from pathlib import Path

import torch
from transformers import AutoModelForCausalLM, AutoTokenizer

MODEL_ID = "Qwen/Qwen2.5-0.5B-Instruct"  # 교육용 선택 모델


def load_questions(path):
    with open(path, encoding="utf-8") as file:
        rows = list(csv.DictReader(file))
    if not rows or not {"id", "question", "reference"}.issubset(rows[0]):
        raise ValueError("CSV에는 id, question, reference 열과 1개 이상의 행이 필요합니다.")
    return rows


def generate(model, tokenizer, question, max_new_tokens):
    messages = [{"role": "user", "content": question}]
    # (변경) 템플릿을 바로 토큰화하여 특수 토큰 중복을 방지한다.
    inputs = tokenizer.apply_chat_template(
        messages, tokenize=True, add_generation_prompt=True,
        return_tensors="pt", return_dict=True
    )
    device = next(model.parameters()).device
    inputs = {key: value.to(device) for key, value in inputs.items()}
    if torch.cuda.is_available():
        torch.cuda.synchronize()
    started = time.perf_counter()
    with torch.inference_mode():
        outputs = model.generate(
            **inputs, max_new_tokens=max_new_tokens,
            do_sample=False, pad_token_id=tokenizer.eos_token_id
        )
    if torch.cuda.is_available():
        torch.cuda.synchronize()
    elapsed = time.perf_counter() - started
    new_tokens = outputs[0, inputs["input_ids"].shape[1]:]
    return tokenizer.decode(new_tokens, skip_special_tokens=True).strip(), elapsed


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--csv", default="lesson06_eval.csv")
    parser.add_argument("--adapter", default=None,
                        help="학습 완료된 PEFT LoRA 어댑터 폴더; 생략하면 기준 모델만 실행")
    parser.add_argument("--output", default="lesson06_results.json")
    parser.add_argument("--max-new-tokens", type=int, default=96)
    args = parser.parse_args()
    questions = load_questions(args.csv)
    tokenizer = AutoTokenizer.from_pretrained(MODEL_ID)
    # CPU 환경에서도 동작하도록 dtype/device 선택. GPU 모델 메모리 상황 확인 필수.
    dtype = torch.float16 if torch.cuda.is_available() else torch.float32
    model = AutoModelForCausalLM.from_pretrained(MODEL_ID, dtype=dtype)
    model = model.to("cuda" if torch.cuda.is_available() else "cpu").eval()
    records = []
    for row in questions:
        answer, seconds = generate(model, tokenizer, row["question"], args.max_new_tokens)
        records.append({**row, "variant": "base", "answer": answer,
                        "seconds": round(seconds, 4)})
    if args.adapter:
        from peft import PeftModel
        if not Path(args.adapter).is_dir():
            raise FileNotFoundError("학습된 LoRA 어댑터 폴더를 찾을 수 없습니다.")
        tuned = PeftModel.from_pretrained(model, args.adapter).eval()
        for row in questions:
            answer, seconds = generate(tuned, tokenizer, row["question"], args.max_new_tokens)
            records.append({**row, "variant": "adapter", "answer": answer,
                            "seconds": round(seconds, 4)})
    Path(args.output).write_text(json.dumps(records, ensure_ascii=False, indent=2),
                                 encoding="utf-8")
    print(f"결과 저장: {args.output}, 레코드: {len(records)}")
    if not args.adapter:
        print("주의: 학습 어댑터 미지정. 학습 전후 성능 비교가 아니라 기준선만 기록했습니다.")


if __name__ == "__main__":
    main()

```
