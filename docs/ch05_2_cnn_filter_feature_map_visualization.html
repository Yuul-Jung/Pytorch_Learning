03CNN 모델 구조 복원

학습 당시와 같은 구조를 만든 뒤 저장된 Weight와 Bias를 넣습니다.

CNN 구조 재생성 후 가중치 복원 Cell 11
CODE원본 코드
def make_cnn():
    return nn.Sequential(
        nn.Conv2d(1, 8, kernel_size=3, padding=1),
        nn.ReLU(),
        nn.MaxPool2d(kernel_size=2, stride=2),

        nn.Conv2d(8, 16, kernel_size=3, padding=1),
        nn.ReLU(),
        nn.MaxPool2d(kernel_size=2, stride=2),

        nn.Flatten(start_dim=1),
        nn.Linear(16 * 7 * 7, 10),
    )

model = make_cnn().to(device)

model.load_state_dict(
    checkpoint["model_state_dict"]
)

model.eval()

class_names_ko = checkpoint[
    "class_names_ko"
]

print("CNN 복원 완료")

05중간 Tensor를 꺼내는 함수

최종 logits뿐 아니라 Conv1, ReLU, Pool1, Conv2, ReLU2, Pool2의 출력까지 직접 확인합니다.

CNN 중간 단계 출력을 모으는 함수 Cell 15
CODE원본 코드
def get_cnn_stages(model, images):
    conv1 = model[0](images)
    relu1 = model[1](conv1)
    pool1 = model[2](relu1)

    conv2 = model[3](pool1)
    relu2 = model[4](conv2)
    pool2 = model[5](relu2)

    flattened = model[6](pool2)
    logits = model[7](flattened)

    return {
        "conv1": conv1,
        "relu1": relu1,
        "pool1": pool1,
        "conv2": conv2,
        "relu2": relu2,
        "pool2": pool2,
        "logits": logits,
    }

코드 풀이 — 이 코드가 무엇을 하는가

일반적인 model(images)는 최종 logits만 돌려주므로, 각 계층을 직접 순서대로 통과시켜 Conv/ReLU/Pooling 중간 Tensor를 모두 보관합니다.

conv1 = model[0](images)
첫 번째 합성곱 직후의 원시 출력입니다. 아직 음수 값이 존재할 수 있습니다.
relu1 = model[1](conv1)
Conv1 출력의 음수를 0으로 바꾼 활성화 결과입니다.
pool1 = model[2](relu1)
28×28 특징맵을 14×14로 축소합니다.
conv2 / relu2 / pool2
두 번째 특징 추출과 활성화, 축소 과정을 같은 방식으로 분리합니다.
flattened = model[6](pool2)
16×7×7 = 784개 특징으로 펼칩니다.
logits = model[7](flattened)
10개 클래스의 최종 점수입니다.
return {...}
각 중간 결과를 이름으로 꺼낼 수 있도록 딕셔너리로 반환합니다.
왜 이렇게 하는가Hook을 사용하지 않고 nn.Sequential의 계층 번호를 직접 호출하기 때문에 초보자가 '어느 계층에서 어떤 Tensor가 나오는지'를 코드와 1:1로 따라가기 쉽습니다.

    model,
    example,
    title
):
    image, true_label, predicted_label = example

    image_input = image.unsqueeze(
        0
    ).to(device)

    with torch.no_grad():
        stages = get_cnn_stages(
            model,
            image_input
        )

    feature_maps = stages[
        "relu2"
    ].detach().cpu()

    scores = feature_maps[0].mean(
        dim=(1, 2)
    )

    top_channels = torch.topk(
        scores,
        k=3
    ).indices

    plt.figure(figsize=(10, 3))

    plt.subplot(1, 4, 1)
    plt.imshow(
        image.squeeze(),
        cmap="gray"
    )
    plt.title(
        f"{title}\n"
        f"A:{class_names_ko[true_label]}\n"
        f"P:{class_names_ko[predicted_label]}"
    )
    plt.axis("off")

    for plot_index, channel in enumerate(
        top_channels,
        start=2
    ):
        plt.subplot(1, 4, plot_index)

        plt.imshow(
            feature_maps[0, channel],
            cmap="gray"
        )

        plt.title(
            f"Conv2 Map {channel.item() + 1}"
        )

        plt.axis("off")

    plt.tight_layout()
    plt.show()

14전체 흐름 핵심 정리

저장된 CNN Checkpoint → 동일한 CNN 구조 생성 → model_state_dict 복원 → Fashion-MNIST 테스트 이미지 [1,1,28,28] → Conv1 [1,8,28,28] → ReLU1 [1,8,28,28] → Pool1 [1,8,14,14] → Conv2 [1,16,14,14] → ReLU2 [1,16,14,14] → Pool2 [1,16,7,7] → Flatten [1,784] → Logits [1,10] → Conv1 Filter / Feature Map / ReLU / Pooling 시각화 → 정답·오답 Conv2 대표 특징맵 비교
  • 학습: 이 Notebook에서는 새 학습을 하지 않고 ch05_1의 저장 CNN을 복원합니다.
  • 저장 성능: Checkpoint의 Test Accuracy 0.8835 → 88.35%
  • Conv1 Filter: 8개 × [1,3,3], Weight 72 + Bias 8 → 80개 파라미터
  • Conv2: 16개 Filter가 입력 채널 8개를 모두 사용 → 1,168개 파라미터
  • 전체 CNN: Conv1 80 + Conv2 1,168 + Linear 7,850 → 총 9,098개 파라미터
  • Shape: 28×28 → 14×14 → 7×7로 공간 크기는 줄고, 채널은 1 → 8 → 16으로 증가합니다.
  • ReLU 실제 출력: 선택된 Conv1 채널은 784개 값이 모두 음수였고 ReLU 이후 음수 0개가 되었습니다.
  • 특징맵 선택: Conv2 평균 활성값이 큰 채널은 관찰용 기준이며, 예측 기여도를 직접 계산한 값은 아닙니다.
  • 시각화 경고: 한글 Glyph 경고는 Matplotlib 폰트 문제이며 CNN 계산에는 영향을 주지 않습니다.
이 Notebook의 핵심: CNN의 '필터 → 특징맵 → ReLU → Pooling'이 추상적인 개념이 아니라 실제 Tensor 값과 이미지로 어떻게 나타나는지를 확인하는 실습입니다. 첫 합성곱은 8개의 서로 다른 반응을 만들고, 두 번째 합성곱은 그 특징들을 다시 조합해 16개의 더 복합적인 표현을 만듭니다. 정답과 오답의 특징맵을 비교할 때는 밝은 반응 위치와 패턴을 관찰하되, 시각화만으로 오분류 원인을 단정하지 않는 것이 중요합니다.
