# PyTorch Lecture Notebooks

PyTorch(파이토치) 핵심 개념을 Google Colab에서 실행하며 이해합니다.

## 학습 흐름

1. 개념 설명을 읽습니다.
2. 코드 셀을 위에서 아래로 실행합니다.
3. 출력 결과와 해설을 비교합니다.
4. 미니 실무 예제와 확인 문제로 복습합니다.

## 실행 환경

- Python(파이썬) 3
- PyTorch(파이토치)
- NumPy(넘파이, 수치 계산 라이브러리)
- 권장 환경: Google Colab
- CPU(시피유, 중앙처리장치)만으로 전체 실습 가능
